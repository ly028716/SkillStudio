# SkillStudio 产品需求评审稿

> **历史规格：** 本文形成于单 Codex 宿主定位。多 Harness 的产品范围、对象和宿主规则已由 [SkillStudio 多 Harness 产品设计](2026-09-05-skillstudio-multi-harness-design.md)取代；本文仅继续提供文件、保存、本地认证和日志等详细约束。

日期：2026-09-05。版本：0.2-draft。已确认：作者与使用者并重；本稿新增规则为建议基线。

## 1. 目标与边界

让用户在自己的本地目录中找到、理解、编辑和校验 Skill，并在宿主能力得到验证时完成一次可追踪运行。Skill 是目录及其 SKILL.md、引用材料的组合，不是可直接执行的脚本。

作者闭环：添加目录 → 从模板创建 → 编辑 → 校验 → 保存 → 试运行 → 查看结果。

使用者闭环：添加目录 → 搜索 → 阅读来源、说明与诊断 → 配置工作目录和任务 → 运行 → 查看结果。

首版包含目录、库、详情、原始 Markdown 编辑、分层校验、复制/ZIP、Codex 运行和本地状态。首版不包含账号、云同步、市场、协作、自动生成 Skill、富文本、Git 写操作、多宿主适配、多任务并行或排队、自动安装依赖、删除或重命名 Skill、ZIP 导入。收藏与最近打开为轻量能力，不扩展成标签管理系统。

目标平台：Windows 11 本机浏览器；桌面视口优先。macOS/Linux 属于后续认证范围，禁止因使用 Node 就宣称跨平台全部可用。

## 2. 需求与验收

### R01 目录连接（P0）

- 入口为“添加本地目录”，输入绝对路径；MVP 不承诺浏览器原生目录选择器返回任意可用系统路径。
- 注册前返回规范路径、读取/写入能力、是否与现有根重叠；用户确认后登记。拒绝重复真实路径、父子重叠根、设备路径及 UNC 网络目录。支持本地中文、空格目录；权限依据实际操作验证，不只依赖 exists。
- 允许只读根用于浏览和运行来源；创建及编辑禁用并给出原因。
- 扫描根本身和子目录中的 SKILL.md；跳过 .git、node_modules、缓存、symlink/junction，显示跳过计数。默认不跟随链接，即使宿主会跟随也不能混用两者规则。
- 状态区分未连接、扫描中、就绪、部分失败、不可访问。部分目录报错不清空成功项。可手动重扫。
- “移除目录”只解除注册，不删除磁盘文件。根下存在活动运行时阻止移除；未保存编辑先完成离开保护。

验收：注册可读根后显示 Skill；中文与空格路径可用；重复/重叠/越界均拒绝；移除后源目录哈希不变；权限失败显示具体目录和重试入口。

### R02 Skill 库与发现（P0）

- 默认展示全部已注册根；按根、诊断严重度筛选，可切换收藏。关键词仅搜索名称、描述与相对路径，暂不全文搜索。
- 名称重复允许存在，身份由规范根和相对路径生成的稳定 skillId 确定，列表显示根别名及相对路径消歧。
- 搜索忽略大小写、去除首尾空白；筛选取交集；无结果可清除条件。
- 默认名称排序，支持最近修改；同值用相对路径稳定排序。索引新鲜度和“重新扫描”明确可见。
- 状态筛选基于已保存内容。草稿诊断不提前覆盖库中的保存状态。

验收：两个根下的同名 Skill 分别打开正确文件；搜索/筛选组合结果稳定；返回库保留查询、选中项和滚动位置。

### R03 详情与创建（P0）

- 详情提供阅读、源码、诊断；显示原始 name、description、根、路径、修改时间、版本摘要及宿主发现状态。
- name/description 缺失时仍可阅读和修复；回退展示目录名，不把回退值悄悄写进源文件。
- 新建表单包含可写根、目录名、name、description。目录名采用工作台约定：小写字母、数字、单连字符，1–64 字符，不以连字符开头结尾，拒绝 Windows 保留名及重名。
- 使用最小模板，预览目标路径与内容后“创建并编辑”。采用排他创建；失败时仅清理本次创建且仍为空的临时目录，不动现有文件。
- 模板必含 YAML name、description 和“适用场景、输入、步骤、输出”正文；不自动添加脚本或依赖。

验收：创建后源目录中只有期望文件；重名不会覆盖；字符串含冒号、引号时生成有效 YAML；只读目录不进入创建提交。

### R04 编辑与保存（P0）

- 编辑器提供行号、Markdown 高亮、显式保存、撤销/重做、草稿校验。MVP 不自动保存、不承诺关闭浏览器后草稿恢复。
- 状态为干净、已修改、保存中、已保存、保存失败、冲突、文件已删除、连接中断。
- 读取返回版本哈希；保存必须携带 baseVersion。每文件串行写入，写前重读比对，不一致返回 409，不覆盖。
- 外部变化：干净文档刷新并提示；脏文档展示“磁盘文件已更新”，提供查看差异、复制草稿、重新载入。重载前确认放弃草稿；MVP 不提供强制覆盖。
- 同目录临时文件写入并 flush，保留受限的一份恢复副本后替换，失败保留旧文件，写后重读。保持现有换行符；新建默认 UTF-8、LF。不支持的编码只读并说明原因。
- 诊断 error 可以保存为草稿；不能据此运行。写入权限、超限、编码和版本冲突属于保存阻断条件。
- 跳转/切换 Skill/关闭面板时有“保存并离开、放弃修改、继续编辑”；浏览器关闭使用原生离开提醒并说明其限制。
- 未保存时点运行，先选择“保存并运行”或“取消”；不静默运行旧内容。保存失败不启动。

验收：两个客户端读取同版本，首个保存成功，第二个 409；失败注入后旧文件可读；用户可复制冲突草稿；连接恢复不丢当前内存草稿；保存成功之前不显示“已保存”。

### R05 分层校验（P0）

| 层 | 示例 | 严重度及行为 |
| --- | --- | --- |
| 文档结构 | YAML 无法解析、重复键、必需字段类型错误 | error；允许修复/保存，阻止运行 |
| 工作台写作约定 | 缺少适用场景、输入或输出说明 | warning；不阻止保存和运行 |
| Codex 兼容规则 | 必需元数据缺失或目标版本明确不接受 | error；规则带来源与版本，不把工作台偏好伪装成官方限制 |
| 宿主能力预检 | 未检测到 CLI、目标 Skill 未被发现、依赖无法确认 | 独立的 blocked/unknown，不作为文档语法错误 |

- 每条诊断提供 code、layer、severity、message、可选 line/column、修复提示、规则版本。
- 编辑后 400ms 防抖，响应携带 draftRevision，前端丢弃旧响应；磁盘校验携带 contentVersion。
- 未知 frontmatter 字段保留并允许通过，不擅自重排或删除。
- Markdown 不因写法灵活就判语法无效；建议规则与解析失败区分。
- 文案：“格式检查不代表内容安全”；不能用绿色徽标证明 Skill 无恶意行为。

验收：错误定位正确；快速连续输入不显示旧诊断；只有警告可以通过运行预检；未知字段保存后原样保留。

### R06 复制与导出（P1）

- 复制路径使用绝对路径；复制内容默认已保存原文。编辑页另有明确“复制草稿”。剪贴板失败展示可手动选择的文本。
- 导出单个 Skill 目录，文件清单预览后打包；包含 SKILL.md、scripts、references、assets 和用户选择的其他普通文件。
- 默认排除 .git、node_modules、链接、工作台备份及 .env/私钥等明显敏感项；展示排除清单，不能声称自动识别所有秘密。
- 路径必须位于该 Skill 下；ZIP 项使用相对路径，拒绝 .. 和绝对项。打包期间检测源变化并中止重试，避免不一致包。
- MVP 限制为 1,000 文件、100 MiB 未压缩大小；超限说明具体原因，不静默截断。

验收：解压后结构一致；排除项可见；目录链接不能导出外部文件；未保存时先保存或取消。

### R07 运行前配置（P0）

- “运行”打开预检配置，不直接执行。字段：Skill 与内容版本、CLI 版本、工作目录、任务描述、权限。
- 工作目录独立于 Skill 根目录，必须存在且由用户为本次任务确认；MVP 仅支持本地 Git 工作目录，不静默启用跳过 Git 检查。
- 默认只读；需要写入时用户明确选工作区写入。禁止提供绕过全部权限和沙箱的选项。
- 预检验证源文件仍在授权根、版本未变、文档无 error、CLI 可用、目标 Skill 可被该工作目录下的宿主发现。登录或依赖未知时如实显示，并允许外部完成配置后重试。
- MVP 只为已验证发现位置的 Skill 开放原生运行。任意注册目录仍可浏览、编辑、复制、导出；未发现时说明宿主发现路径，不自动安装、复制、写配置或将正文拼接伪装成原生调用。
- 名称重复且无法证明选择的是目标路径时阻止执行。发现路径只作必要条件，最终加载机制必须通过集成样例验证。
- 参数由连接器构建白名单 argv；任务文本从 stdin 传入，不交给 shell。适配器探针要验证提示中的名称不会匹配其他 Skill，路径及引用附件正确。
- 运行会向配置宿主交付任务与 Skill 信息，可能访问其模型服务；在运行配置中简洁说明，不承诺离线。

验收：无 CLI、不可发现、同名无法消歧、未保存、缺工作目录均有明确恢复动作；取消预检无进程；任务文本包含引号、换行、$() 时仍仅作为文本传递。

### R08 运行与日志（P0）

- 全应用同时只允许一个活动运行，不排队；重复提交同一 clientRequestId 返回同一 runId。
- 生命周期：preflighting → starting → running → succeeded/failed；活动态可转 cancelling → cancelled/cancel_failed；超时为 timed_out，连接器异常恢复为 interrupted。
- succeeded 仅在进程退出码 0 且记录到有效完成事件时成立；这只表示宿主执行完成，不保证任务结论正确。没有完成事件时标失败并记录原因。
- 取消按钮立即显示“正在停止”；实机验证进程树终止，确认退出后才标已取消。停止失败进入 cancel_failed，保留活动锁直到确认进程退出，禁止立即重启任务。
- 默认超时 30 分钟；前端断线不主动取消运行。重连按 seq 补传，缺段明确展示；前端丢弃重复事件。
- 每条日志带 runId、seq、time、kind、text。stdout JSONL 分块重组；未知事件保留为文本，不能使解析器崩溃。stderr 独立保存。
- 前端默认渲染最近 2,000 行并虚拟滚动；每次运行日志上限 10 MiB，超限继续排空管道但标记截断。退出信息独立保存。
- 运行中不允许通过工作台编辑该 Skill；检测外部源变化时标记 sourceChanged，结果注明“运行期间源已变化”，不承诺可复现快照。

验收：双击只有一个进程；断线重连不重跑；日志乱序/重复能恢复；取消能终止测试子进程；超大输出不耗尽内存；连接器重启不将未知状态报告成功。

### R09 本地状态和记录（P1）

- SKILL.md 及其资源为内容真实来源。派生索引只存元数据、诊断和文件状态，可重建。
- 根注册、收藏、最近打开为用户状态，不能通过扫描重建，单独持久化和版本迁移。
- 运行摘要、任务文本、受限日志为本地记录，默认保留最近 100 次且最多 30 天；按先达到的限制清理，活动任务除外。恢复副本每文件一份、最多 7 天。
- 用户可在记录页清理历史，不删除 Skill。清理前提示任务文本/日志不可恢复；活动任务不可清理。
- 断开的根对应收藏标记不可用，不偷偷删掉。记录保留路径快照，即使源移除也可以读摘要。

验收：重建索引不清空收藏和目录；异常 JSON 可从上一份有效用户状态恢复；到期清理不删除活动任务或源文件。

### R10 本地连接边界（P0）

- 服务只监听 127.0.0.1，单进程提供前端与 API；校验精确 Host 和 Origin，禁止跨源通配与路径型文件 API。
- 启动生成一次性随机凭据，通过浏览器 URL fragment 交给首屏，交换会话后立即清理 fragment；凭据 60 秒过期、单次使用，不写日志。
- 会话使用随机令牌，仅保存在当前页面内存，刷新由本机启动器重新建立；HTTP 用 Authorization，WebSocket 首消息认证，5 秒未认证即关闭，认证前不发送任何数据。
- HTTP 会话 8 小时过期；令牌不置于查询串、持久 localStorage 或诊断包。第三方站点和无认证请求无法枚举目录或启动运行。
- Markdown 禁止原始 HTML，链接限制为受控协议；默认不自动请求远程图片。日志按纯文本渲染，防止源文件或工具输出执行脚本。
- ID 映射到服务器持有的规范路径；路径边界验证覆盖读取、写入、创建、导出、运行预检，不只检查注册步骤。

验收：未认证、错误 Origin/Host、过期令牌、链接越界均拒绝；XSS 样例不执行；令牌不出现于普通日志和 URL 查询。

### R11 质量与成功指标（P1）

以下为计划目标，尚未测量：

| 指标 | 验收方式 |
| --- | --- |
| 作者能在 5 分钟内创建并保存一份无 error 的 Skill | 5 名代表用户完成预设任务，至少 4 名无需主持人代操作 |
| 使用者能在 3 分钟内找到指定 Skill 并进入就绪预检 | 已注册目录、CLI 已配置的前提下，另一个独立任务至少 4/5 成功 |
| 首扫 1,000 Skill ≤ 5 秒，搜索 p95 ≤ 150ms | Windows 11、4 核/16GB/本地 SSD、单 Skill 20KiB，记录基准环境与原始结果 |
| 草稿诊断 p95 ≤ 800ms | 100KiB 文档，含 400ms 防抖，至少 30 次测量 |
| 已保存文件变化通常 2 秒内展示 | 正常 watcher；异常时提供手动重扫且显示索引时间 |
| 源文件上限 1MiB | 超限只展示元信息及原因，禁止加载到编辑器；扫描上限 10,000 Skill 后显式提示范围不完整 |
| 无障碍目标 WCAG 2.2 AA | 自动扫描加键盘、屏幕阅读器及缩放人工检查；不能由截图认定通过 |

## 3. 发布定义

R01–R11 的 P0/P1 均有对应证据后才称完整 MVP。仅完成浏览编辑阶段可作为内部里程碑，不改称“运行已支持”。至少完成创建、外部冲突、只读根、重复名称、真实 Codex 运行、取消、断线和恶意路径样例。测试不得使用用户真实重要目录作为破坏性夹具。
