# SkillStudio

> 面向本地 `SKILL.md` 的工作台：创作、发现、校验、导出，并在可用时一键交给本地 Agent 宿主运行。

## 项目目标

SkillStudio 是一个运行在本机的 Web 工作台，服务于两类用户：

- **Skill 作者**：从模板创建、编辑和校验本地 Skill。
- **Skill 使用者**：浏览、搜索、检查并运行已有 Skill。

首个版本聚焦一个可验证的闭环：**创作 → 发现 → 校验 → 运行**。Skill 文件保留在用户指定的本地目录中，而不是复制到工作台数据库。

## MVP 范围

### 包含

- 添加、移除和切换本地 Skill 根目录；扫描其中的 `SKILL.md` 文件。
- Skill 列表、关键词搜索和按诊断状态筛选。
- Skill 详情页：元数据、原始内容、目录位置与兼容性诊断。
- 从最小模板创建新的 Skill 目录和 `SKILL.md`。
- 原始 Markdown 编辑、即时校验、原子保存和外部文件变更提醒。
- 分层校验：通用 Markdown、工作台元数据约定、Codex 兼容规则。
- 复制路径、复制内容和导出 ZIP。
- 检测本地 Codex CLI；通过受控参数运行并显示实时日志与最近记录。
- 连接器状态页：目录权限、扫描状态、CLI 状态和诊断信息。

### 不包含

- 云端同步、账号、团队协作或权限管理。
- 公共 Skill 市场、在线发布、评分或支付。
- 可视化工作流、多 Agent 编排、定时任务或跨机器运行。
- 富文本编辑器、自动生成 Skill 或复杂依赖安装。
- Codex 以外的深度宿主集成；其他 CLI 仅保留后续适配空间。

## 架构概览

```text
浏览器（React + TypeScript）
  ├─ Skill 库、搜索与详情
  ├─ Markdown 编辑器与诊断
  └─ 运行面板与日志
              │ HTTP / WebSocket，仅 localhost
本地连接器（Node.js）
  ├─ 受控目录的扫描、读取、原子写入与文件监听
  ├─ SKILL.md 解析与分层校验
  ├─ Codex CLI 检测与受控运行适配器
  └─ 本地轻量索引（收藏、最近打开、运行记录）
              │
用户明确注册的本地 Skill 根目录 / 本地 Agent CLI
```

## 安全与数据原则

- 连接器只绑定 `127.0.0.1`，不提供远程访问。
- 首次启动时生成本机随机令牌，前端请求必须携带该令牌。
- 只访问用户显式注册的目录；拒绝目录穿越与符号链接越界。
- 启动 CLI 时使用结构化命令和参数，不经由 shell 拼接执行。
- 每次运行前执行 CLI、Skill 路径和工作目录预检。
- `SKILL.md` 是唯一真实来源；本地索引只保存可重新生成的派生信息。
- 保存采用临时文件加原子替换，降低意外中断损坏文件的风险。

## 计划中的技术栈

| 模块 | 选择 |
| --- | --- |
| 前端 | React、TypeScript |
| 本地连接器 | Node.js、TypeScript |
| 通信 | localhost HTTP API + WebSocket 日志流 |
| 文件与索引 | 本地文件系统 + JSON 索引（MVP） |
| 首个运行宿主 | Codex CLI |

## M0 开发状态

M0 已提供本地 Harness 能力状态页、回环 Connector 和共享发现契约。它的目标是展示可复核的安装、版本、执行与 Skill 发现证据，不是启动 Harness 或运行 Skill。

当前范围严格限定为只读诊断：Connector 仅监听 `127.0.0.1`，不访问用户 Skill 文件；Codex 的命令与版本有实测证据，Hermes 仅有源码版本证据且运行时仍需验证，DeepSeek 仅提供静态兼容性诊断并在 M0 标记为不支持执行。

开发命令和本地启动方式见 [M0 开发说明](docs/development.md)，能力结论与原始探针记录见 [ADR 0001：M0 Harness 能力基线](docs/decisions/0001-harness-capability-baseline.md)。
